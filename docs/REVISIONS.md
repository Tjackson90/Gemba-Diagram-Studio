## Correctness and reliability

- Corrected augmented, Sus2, add9, ninth, half-diminished templates and D9 override;
  tested all roots/qualities against expected pitches and defining intervals.
- Shifted triads as complete shapes instead of wrapping individual strings.
- Centralized pitch selection and timestamped note events for audio, tabs/video.
- Eliminated accumulated frame rounding; progression panels follow actual audio
  durations. Videos preserve selected box/full views and titles.
- Added a current-document model and reset mutually exclusive state on mode changes.
- Captured immutable export jobs; one cancellable worker returns results to the
  main GUI thread. Tone settings are isolated per job.
- Persisted queues, retained failures/cancellations, counted actual successes,
  and added reordering, removal, retries, and collision-safe filenames.
- Corrected PNG compositing, explicit float WAV encoding, MP3 sample rates, and
  shared FFmpeg discovery. Removed the pydub requirement.
- Added validated atomic JSON storage, backups, corruption errors, and user-data
  directories independent of the application installation.
- Captured all modes/settings for history, favorites, lessons, and undo/redo.
- Corrected M7/M9 parsing, diatonic spelling, pentatonic patterns, and explicit key
  mode for custom progressions. Generic positions are called exploratory windows.

## Intentional boundaries

- No cloud hosting, account system, updater, or language/framework migration.
- The legacy custom chord identifier keeps its separate image export controls;
  native-resolution rendering and video queue apply to generated diagrams.
- SVG exports use a clean vector layout rather than reproducing bitmap effects.
  PDF embeds high-resolution raster artwork.
- Alternate-tuning finger suggestions are algorithmic. Review unusual/custom
  interval sets and suggested stretches for the intended teaching exercise.
- Audio remains synthesized; sample-library recording and subjective mastering
  were not part of the correctness revisions.
- FFmpeg remains an external dependency for MP3/video.
- See README for migration, supported workflows, tests, and build instructions.
